# BUG-001 — Oversized employee or plan ID raises an uncaught exception

## Requirement and impact
R08: reject invalid input. Medium severity: a crafted oversized ID escapes normal validation and fails the request instead of returning a controlled rejection.

## Reproduction
Baseline: original app at commit 1bc2e360ed15b4465e47b70866280d8a8b2e6bd7, fictional sample database.
Call enroll(conn, '999999999999999999999999999999', '1', '2026-10-10').

Expected: invalid-input rejection and no database write.
Observed before fix: OverflowError: Python int too large to convert to SQLite INTEGER.
The original finding was reproduced through the unchanged enrollment function, not through a browser.

## Fix
Validate positive integer IDs against SQLite's signed 64-bit range before querying, reject booleans/floats, and apply consistent validation to plan/dependent IDs. Normalize dependent IDs before duplicate detection.
